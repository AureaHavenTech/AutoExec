| File | Purpose |

### What the App Does

When built and installed, the app opens a full-screen WebView that loads `https://axelai-eight.vercel.app`. All functionality (chat, auth, Stripe, Shopify, etc.) runs on the Vercel-hosted Next.js server. The Android shell provides:
- A native app icon on the home screen
- Full-screen, no-browser-chrome experience
- Deep-link / custom URL scheme support (`com.aurahaventech.axelai://`)
- Google Play Store listing potential

## Remaining Steps (Owner / Developer With Java)

### 1. Install Prerequisites (one-time)

**On Linux:**
```bash
# Ubuntu/Debian
sudo apt install openjdk-17-jdk android-sdk

# Or manually: download Android Studio, which bundles everything
# https://developer.android.com/studio
```

**On macOS:**
```bash
brew install openjdk@17
# Then install Android Studio for the SDK
```

**On Windows:**
Install Android Studio (bundles JDK + SDK + Gradle).

### 2. Set Environment Variables

```bash
export JAVA_HOME=/path/to/jdk-17
export ANDROID_HOME=/path/to/android-sdk
export PATH="$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/platform-tools:$PATH"
```

### 3. Accept Android Licenses

```bash
yes | $ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager --licenses
```

### 4. Build the Project

```bash
cd native/android

# Install deps if first time (deps already installed; just verify)
npm install

# Build debug APK (for testing)
cd android
./gradlew assembleDebug
# Output: android/app/build/outputs/apk/debug/app-debug.apk

# Build release AAB (for Play Store submission)
./gradlew bundleRelease
# Output: android/app/build/outputs/bundle/release/app-release.aab
```

### 5. Sign the Release Build (for Play Store)

You need a **keystore** — this is a password-protected file that identifies you as the app's author. **Guard it permanently.** If you lose it, you cannot update your app on the Play Store ever again.

**Generate a keystore:**
```bash
keytool -genkey -v \
  -keystore axel-ai-release.keystore \
  -alias axelai \
  -keyalg RSA \
  -keysize 2048 \
  -validity 10000 \
  -storepass CHOOSE_A_STRONG_PASSWORD \
  -keypass CHOOSE_A_STRONG_PASSWORD \
  -dname "CN=Aura Haven Tech, OU=Development, O=Aura Haven Tech, L=City, S=State, C=US"
```

**Sign the AAB:**
```bash
jarsigner -verbose \
  -sigalg SHA256withRSA \
  -digestalg SHA-256 \
  -keystore axel-ai-release.keystore \
  -storepass YOUR_PASSWORD \
  -keypass YOUR_PASSWORD \
  android/app/build/outputs/bundle/release/app-release.aab \
  axelai
```

### 6. Submit to Google Play Console

1. Log in to [Google Play Console](https://play.google.com/console) (owner's $25 account)
2. Create a new app: package name `com.aurahaventech.axelai`
3. Upload the signed `app-release.aab` to the **Internal testing** track first
4. Complete the **Data safety** form
5. Add app description, screenshots, feature graphic (1024×500px)
6. Set content rating via the questionnaire
7. Roll out to **Production** when ready

### 7. Keep the Keystore Safe

- Store `axel-ai-release.keystore` and its password somewhere secure (password manager + encrypted backup)
- You'll need it for every future app update
- If lost, you must create a new app listing with a new package name
